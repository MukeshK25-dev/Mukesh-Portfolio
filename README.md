# Mukesh Portfolio 🌐

Personal portfolio website showcasing my projects, skills, education, and
journey as a Python/Backend Developer and final-year B.Tech Information
Technology student.

---

## 📖 Overview
A static personal site built with plain HTML/CSS/JS — no framework — covering
who I am, what I've built, and how to reach me. Intended as the front door to
my [GitHub](https://github.com/MukeshK25-dev) for recruiters and hiring
managers.

## 🚀 Features
- About / bio section
- Skills overview
- Project showcase with links to GitHub repos
- Downloadable résumé
- Contact section

## 🛠️ Tech Stack
- HTML5, CSS3, vanilla JavaScript
- No build step / no framework dependencies

## ⚙️ Installation & Usage

```bash
git clone https://github.com/MukeshK25-dev/Mukesh-Portfolio.git
cd Mukesh-Portfolio
# open index.html directly in a browser, or serve it:
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
